Data Manager

Atualização da API e consolidação dos dados oficiais por navegador, com cópia de segurança privada, validação do GitHub, importação incremental e registo de operações.

1. Estado e acesso

O painel utiliza apenas a API EarnWage em produção. As operações de escrita exigem a chave de administração já configurada no servidor como EARNWAGE_ADMIN_TOKEN (mínimo 32 caracteres). A chave não é guardada em ficheiros, cookies ou localStorage. Não a coloques no GitHub nem a envies por mensagem.

A aguardar consulta.

2. Atualizar a API a partir do GitHub

Atualiza o servidor com a versão main do repositório EarnWage. O servidor só aceita a atualização quando os API tests dessa versão terminaram com sucesso.

Proteção: são atualizados apenas app/*.py, data/*.json, scripts/*.py, passenger_wsgi.py e requirements.txt. Bases SQLite, .htaccess, variáveis privadas e backups nunca são substituídos.

Por executar. Esta operação cria primeiro uma cópia do código atual e pede o reinício do Passenger.

3. Proteger a informação existente

Antes da primeira importação: cria uma cópia privada das bases SQLite efetivamente utilizadas pelo Passenger. A operação não elimina nem substitui quaisquer observações.

Por executar. Sem uma cópia verificada, o Data Manager recusa novas importações.

4. Escolher o que atualizar

Nova ronda de dados: os botões «Novos 16» consultam apenas segurança, corrupção, emprego, saúde e ambiente. São até 16 consultas por país ou 224 nos 14 países, uma de cada vez. Mantém esta página aberta durante a execução. O modo é automaticamente «Completar»; se a importação parar, podes retomá-la sem voltar a consultar observações já guardadas.

Cada pedido processa um indicador num país. Os valores anteriores permanecem na base de dados se a fonte falhar. «Completar» não serve para o calendário recorrente: a atualização normal tem de voltar a consultar os dados existentes.

Saúde: o indicador health_coverage é o índice OMS de cobertura dos serviços essenciais (ODS 3.8.1; metodologia de 2025), de 0 a 100 pontos. Não é a percentagem de habitantes com acesso ao SNS ou a um seguro, nem mede a proteção financeira. A fonte principal desta série é a OMS; o Banco Mundial disponibiliza o espelho oficial SH_UHC_SCI. Importa primeiro Portugal e confirma o ano e as observações antes dos restantes países.

Nenhum pedido em curso.

O painel está pronto.

6. Atualização automática

A rotina automática é preparada no GitHub Actions e comunica com esta mesma API protegida. Para a ativar, é necessário configurar uma única vez a chave em GitHub → Settings → Secrets and variables → Actions e autorizar o agendamento. Sem essa configuração, as importações automáticas não devem ser consideradas ativas.

As tarefas automáticas devem fazer consultas pequenas, manter os períodos e fontes originais e nunca inventar salários ou trocar médias de grandes grupos por valores de profissões específicas.
