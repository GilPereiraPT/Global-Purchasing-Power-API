Metodologia

Estes valores correspondem à remuneração base mensal publicada para o ponto inicial de uma carreira pública. Não são uma média salarial portuguesa, não abrangem automaticamente o setor privado e não incluem suplementos, subsídio de alimentação nem cálculos de salário líquido. A associação condicional a uma carreira geral só é aplicável se o recrutamento ocorrer efetivamente nessa carreira e forem cumpridos os requisitos de ingresso.
