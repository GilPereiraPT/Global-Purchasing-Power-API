O que está efetivamente guardado na nossa API: indicadores, períodos, séries históricas, salários e fontes. Sem confundir código disponível com dados importados.

A aguardar consulta.

Leitura direta da API de produção. Uma célula «Não importado» significa apenas que não existem observações guardadas nesta base de dados. Não significa que a entidade estatística não publique o indicador. A existência do script não prova que o agendamento esteja ativo.

O que este inventário mede

Banco Mundial: séries anuais independentes. Eurostat/ONS/OCDE: três séries económicas distintas. Salários profissionais: observações de profissões específicas, separadas das médias de grupos ISCO-08. Câmbio: apenas taxas BCE encontradas na cache local; uma cache vazia não implica ausência de câmbio na fonte.

Este ecrã não cria nem atualiza estatísticas: lê o que existe no processo da API. A importação do Banco Mundial e do Eurostat tem de ser executada no servidor. A data da última importação não altera o ano da observação oficial.
