Como interpretar os resultados

HTTP 200 significa que o pedido foi respondido, não que existam salários ou vagas. Verifica status, reason, observations, unidades, fontes e datas no JSON. HTTP 503 indica falha do serviço/fonte externa. Erro CORS significa que o navegador bloqueou a leitura; não prova que a API esteja offline.

Os anos acima são apenas controlos de validação: os endpoints de inflação existentes devolvem a série disponível, não aceitam anos inicial/final como parâmetros. A pesquisa de emprego agrega Remotive (remoto) e Arbeitnow (localização anunciada), sem garantir cobertura nacional exaustiva.
