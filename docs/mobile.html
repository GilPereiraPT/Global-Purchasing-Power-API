Como ler o EarnWage

Um traço significa que essa camada não tem uma observação validada; não significa salário zero. As fontes e períodos podem variar entre países. O objetivo é preservar a natureza estatística de cada valor antes de avançarmos para fiscalidade, custo de vida e poder de compra.
