Administração de indicadores económicos

Importação manual de indicadores oficiais, sem Terminal. A chave nunca é guardada no navegador.

1. Acesso protegido

Esta página só consegue importar dados quando o servidor tiver a variável EARNWAGE_ADMIN_TOKEN configurada com uma chave privada de pelo menos 32 caracteres. Não publiques a chave no GitHub nem a envies por mensagem.

2. Importar dados

Cada pedido importa um único indicador de um país. Uma falha não elimina os dados anteriormente importados.
